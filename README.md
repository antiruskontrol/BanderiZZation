## 🛠 Стек технологій (Tech Stack)
Проєкт побудований на базі чистих та сучасних веб-технологій без важких фреймворків, що забезпечує максимальну швидкість завантаження (важливо для SEO):
* **HTML5** (Семантична розмітка та структура)
* **CSS3** (Сучасна адаптивна верстка та анімації)
* **Vanilla JavaScript** (Логіка ігор та взаємодія)

## 🤝 Як долучитися до розробки (How to Contribute)
Ми відкриті до співпраці! Якщо ви frontend-розробник, дизайнер або сценарист і хочете додати свою гру чи покращити існуючу:
1. Зробіть **Fork** цього репозиторію.
2. Створіть свою гілку (`git checkout -b feature/AmazingGame`).
3. Зробіть **Commit** ваших змін (`git commit -m 'Add some AmazingGame'`).
4. Надішліть **Pull Request**.
